# Test Models

These are deliberately simple, clean test geometries for the first Cursor build.

Use them to test:
- STL import
- OBJ import
- bounding box calculation
- normalization / centering
- camera framing
- particle flow around simple objects
- statistics panel updates
- video export

Files:
- `cube.stl`
- `sphere.stl`
- `cylinder.stl`
- `vehicle_block.stl`
- `simple_airfoil.obj`

Built-in **Plane** demo (fuselage, wings, tail) is available in the app under Demo Objects — no file import required.

Do not begin testing with complex Sketchfab or GrabCAD models. Get these primitives working first.
